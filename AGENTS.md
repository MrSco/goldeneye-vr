# Repository identity

Use only the **MrSco** GitHub account when working on `MrSco/goldeneye-vr`, including issues, pull requests, comments, reviews, commits and pushes.

- Verify that the active GitHub connection reports the login `MrSco` before repository operations in each session. Do not assume that the environment default, CLI credentials or a different connector uses the same account.
- For local commits, set repository-local `user.name` to `MrSco`, `user.email` to `MrSco@users.noreply.github.com`, and `user.useConfigOnly` to `true`. Verify both author and committer identities before publishing. Never inherit another repository's global identity.
- GitHub-created commits must be attributed to the verified `MrSco` account.
- If the required identity cannot be verified, stop before remote writes and report the missing account access. Never substitute another account.
