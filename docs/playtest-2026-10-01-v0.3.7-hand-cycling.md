# v0.3.7 independent hand cycling release

Continued in the existing playtest-logging-feedback-731f59 worktree. Earlier
multiplayer, launcher, combat-memory, ammo, crash-reporting, voice and HUD changes
remain in this release. No push, deployment, report upload or headset installation.
Only the release APK is delivered.

## Changes

- Logical dominant A taps cycle only the dominant hand. Logical off-hand X taps
  cycle only the off hand, including holstering. Grip plus tap reverses that hand.
  Holding either button for 350 ms opens its distinct-item selector; releasing
  after moving the highlight equips only that hand. Existing left-handed role
  mapping remains in use. Menus, return prompts, gun fitting and flat input retain
  their controls; a disabled off hand does not fall back to primary cycling.
- Firearms and throwables can mix across hands in solo and multiplayer Any mode.
  Watch devices, detonator, tank shells and mission items remain dominant-only.
  Host Off/Doubles restrictions still apply. No generated pairs are inserted
  into the inventory. Weapons already carried only in native pairs are listed
  individually. An equipped off hand still fires with an empty dominant hand.
- Native pair validation during the switch animation no longer holsters or
  rejects a VR hand's mixed weapon. Flat gameplay retains native behavior.
  Rapid reversal also updates an already queued request before its first tick.
- Empty magazine plus empty reserve advances only the depleted hand, skipping
  unavailable ammo and mission gadgets; otherwise it holsters. This checks that
  hand's trigger release, allowing the other hand to keep firing. The dominant
  remote-mine detonator transition and exiting a tank remain available.
- Android versionName is 0.3.7, versionCode 46. Multiplayer wire protocol remains
  14; this input change requires no additional packet fields.
