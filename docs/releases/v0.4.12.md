# GoldenEye VR v0.4.12

A quick fix release: the GoldenEye X remote mine's detonator watch now sits
right in your off hand by default.

> **Bring your own game.** This APK contains no GoldenEye or Perfect Dark game
> data. You need a legally obtained ROM of the USA GoldenEye 007 cartridge you
> own. Installing over an earlier release keeps your ROM and settings.

> **Multiplayer compatibility.** The network protocol is unchanged at **19**, so
> v0.4.11 and v0.4.12 players can play together.

## GoldenEye X remote mine detonator

- **Detonator watch fit.** With GoldenEye X on, the watch GE-X's left hand holds
  for the remote mines now defaults to a position and angle fitted in the
  headset. Previously it had no default fit. Gun fit's off hand mode (with
  remote mines out) still adjusts it, and a saved fit still takes precedence.
- **Fit angles.** Turning the detonator watch in Gun fit keeps each angle within
  a half turn either side, like the gun hand and off hand turns, so the readout
  stays readable.

## Installation

Use **Update** in the headset launcher when v0.4.12 appears, or install
`GoldenEye-VR-v0.4.12.apk` over your current version with SideQuest or ADB. It
uses the existing release signing key. See the
[install guide](https://github.com/MrSco/goldeneye-vr#-install-it-in-5-steps).

Android version: `0.4.12`; versionCode: `67`; network protocol: `19` (unchanged).
