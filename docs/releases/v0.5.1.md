# GoldenEye VR v0.5.1

Bullet wounds on XBLA heads, and a tidier Mods page.

## Project Bean (XBLA visuals)

- Head shots now leave a wound on Bean guards' heads, where the shot landed.
  A Bean head is its own mesh, so in v0.5.0 a head shot's wound went to the
  body's collar and the face stayed clean. As in Dab's Mod, a head wound
  covers a smaller area than a body wound, and hits elsewhere no longer mark
  the head.

## Launcher

- **Mods:** the Blood patch checkbox has its own row above Done again. The
  page still fits without scrolling in every download state.

## Validation

- Checked on Quest 3: head-shot wounds on Bean guards and the Mods page
  layout.
- Native regressions cover the skin shader's head and body wound radii and the
  Mods page in every download state at Quest font size.

## Update and multiplayer compatibility

Download `GoldenEye-VR-v0.5.1.apk` or use **Update** in the headset launcher.
Updating over an earlier release keeps your settings. This APK contains no
GoldenEye, XBLA or Perfect Dark game data; use your existing game files.

Android version: `0.5.1`; versionCode: `81`; network protocol: `21`.
v0.4.16 through v0.5.1 share the same multiplayer protocol.
