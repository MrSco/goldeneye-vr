# GoldenEye VR v0.4.9

Smooth VR locomotion, fitted muzzle flashes and calibrated belt reloads.

> **Bring your own game.** This APK contains no GoldenEye or Perfect Dark game
> data. You need a legally obtained ROM of the USA GoldenEye 007 cartridge you
> own. Installing over an earlier release keeps your ROM and settings.

## Changes

- Joystick movement and smooth body turning interpolate across headset frames,
  reducing recurring movement steps even when the FPS counter is stable.
- Physical head movement, controller-held objects and HUDs retain current
  tracking. Gameplay speed, collision, aiming and multiplayer state keep their
  existing behavior; virtual-screen rendering is unchanged.
- Interpolation resets on teleports/respawns, snap turns, recentering, pause,
  tank transitions, tracking/session loss, display-rate changes and long stalls.
- Performance status now distinguishes simulation ticks, fresh renders,
  intermediate redraws and XR submissions, and shows worst render/submission
  gaps, interpolation delay and missing-history clamps.
- Independently moving actors retain their existing simulation cadence.

## Barrel-tip fitting and GE-X muzzle flashes — PR #126

- Gun Fit now includes Barrel Tip mode with separate saved per-weapon fits for
  GoldenEye and GE-X. Muzzle flashes follow the fitted bullet origin while the
  forearm and watch rig retain their animation.
- The user's GE-X KF7 muzzle calibration is now the new-install default:
  `GexMuzzleKF7=4.07 2.87 -7.23`. Existing saved fits continue to override it.
- Application builds now target Android/Quest; shared engine code and native
  test fixtures remain available.

## Calibrated belt reloads — PRs #124 and #125

- Belt reloads use the fitted belt radius for both hands and all reloadable
  guns, with a rearm margin to avoid repeated reloads and buzzing from jitter.
- GE-X magazine-fed guns can top up at the belt with the magazine inserted or
  out, preserving magazine/reserve ammo and explicit magazine handling.
- Successful holster/use gestures take priority. A downward reach toward the
  fitted belt reloads a gun needing ammo; other melee approaches remain available.
- Hand reload settings are grouped under the watch's VR: GESTURES page.

## Validation

The user tested the patched build on Quest and reported smooth movement. Native
locomotion, display, surface, collision and hand-reload checks, 64 multiplayer
tests and 20 Android unit tests passed before the version bump. Tests were not
rerun for the version bump. The full refresh-rate/QGO/co-op comparison matrix
remains unverified; see [validation details](https://github.com/MrSco/goldeneye-vr/blob/v0.4.9/docs/vr-locomotion-validation.md).

## Installation

Use **Update** in the headset launcher when v0.4.9 appears, or install
`GoldenEye-VR-v0.4.9.apk` over your current version with SideQuest or ADB. It
uses the existing release signing key. See the
[install guide](https://github.com/MrSco/goldeneye-vr#-install-it-in-5-steps).

Android version: `0.4.9`; versionCode: `62`; network protocol: `18` (unchanged).
