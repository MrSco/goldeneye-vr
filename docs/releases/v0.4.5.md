# v0.4.5

- **Virtual screen passthrough background:** optional Meta Quest passthrough
  (`XR_FB_passthrough`) behind the 2D virtual screen, toggled via a new
  "Passthrough background" checkbox in the launcher's **SCREEN** tab and saved
  to `goldeneye-vr.ini` (`ScreenPassthrough=1`). Shows your physical room
  instead of the black void during menus, cutscenes, 2D gameplay, and the
  in-game pause screen. Passthrough automatically pauses during stereo VR
  gameplay for full immersion and to save battery.
- **Frigate hull decals and recessed fixtures:** fixed room decal stencil
  handling so later primitives properly overwrite earlier primitives in the
  same display batch, correctly rendering the white "06" hull marking with its
  black drop shadow. Restored the room color pass pull so recessed fixtures
  (such as bollards in wall alcoves) remain intact without clipping or
  flickering while moving past.
- **Co-op Ready button (#107):** fixed an issue where the "Ready" button on the
  co-op launcher page was greyed out for joiners when the host had certain
  deathmatch scenarios selected.
- **Sniper aiming:** aiming with "Aim: no lean" zooms smoothly without stepping
  Bond forward or backward.

Android version name: `0.4.5`; version code: `58`; network protocol remains `17`.

## Validation

NDK sources compile cleanly, all native tests (surfaces, launcher UI, display,
pause UI, v0.4.3, watch grip, and multiplayer) pass, and the signed release
APK builds and installs over v0.4.4 on Quest 3.
