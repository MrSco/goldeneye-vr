# GoldenEye VR v0.4.19

Fixes for offhand two-handed aiming, mission gadgets and the watch laser,
plus ROM validation and a startup decompressor crash fix.

This APK contains no GoldenEye or Perfect Dark game data. Use your existing
USA GoldenEye 007 ROM. Updating over an earlier release keeps your settings.

## Hands, aiming and scopes

- Valid controller poses now keep updating during temporary tracking occlusion.
  A two-handed hold follows those poses instead of freezing both hands until
  full tracking returns. Invalid poses retain their last known room position;
  inferred velocities do not start motion throws or melee attacks.
- Retained controller poses and the scope lens use the current headset frame
  consistently, addressing the lens locking to the headset and jumping against
  the gun between frames when supporting an offhand weapon.

## Gadgets and the watch

- Either hand can select handheld mission equipment already in inventory from
  the gadget belt, including the Dam's covert modem. A mission device can be
  held by one hand at a time; pending or stale selections cannot duplicate it.
- The GoldenEye X offhand gadget and hand use the same fitted origin and
  reflection. The watch stays attached to the posed offhand forearm while it
  holds a gadget.
- The watch laser is available from either gadget belt selector. Selecting it
  always equips its usual watch and firing-hand arrangement, respecting
  handedness mode. Drawing another item with the offhand exits the laser setup
  and keeps the replacement instead of having the watch rig cancel it.
- Using the key analyser or weapon case equips its result into the initiating
  hand in VR. The other hand keeps its item.

## Startup and launcher

- PR #168 checks every manifest-listed compressed ROM resource before starting
  the game and bounds resource decompression. Damaged or incompatible data
  produces a ROM error instead of letting that decoder read past its input.
- Fixes the immediate launch crash introduced by the first PR #168 test APK:
  the cartridge decoder's exported `inflate` name intercepted zlib's function.
  The legacy entry point now stays private, and a regression test links both
  decoders together.
- The multiplayer Players dropdown includes enough width for the full label.

## Validation and remaining checks

- All 43 Python regression files pass. Native checks cover controller pose validity,
  between-frame grip
  and scope transforms, gadget ownership and use, both gadget hand models,
  watch-laser selection and replacement, body slots, launcher layout and bounded
  ROM decoding. The signed ARM64 release builds with JDK 20 and the existing
  release certificate.
- The latest combined changes still need headset playtesting, including startup,
  gadget fit, controller occlusion and offhand slot draws with the watch laser.
  Automated checks do not confirm how these look and feel in the headset.
- Multiplayer checks on two headsets remain outstanding.

## Installation and multiplayer compatibility

Download `GoldenEye-VR-v0.4.19.apk` or use **Update** in the headset launcher.
Install it over your current version using your preferred installer.

Android version: `0.4.19`; versionCode: `74`; network protocol: `21` (unchanged).
v0.4.16, v0.4.17, v0.4.18 and v0.4.19 use the same multiplayer protocol.
