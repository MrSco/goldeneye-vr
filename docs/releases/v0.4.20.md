# GoldenEye VR v0.4.20 — withdrawn candidate

Version code 75, network protocol 21. This candidate is not published.
Build `0bf6179` failed Quest 3 runtime testing (report `a2167162`): a Dam aiming
crash and incorrect model/texture rendering. Do not publish the archived APK.

The follow-up fixes native collision pointer ownership, stale model
registrations, decoded image orientation, magenta-placeholder substitution
and opaque vertex alpha. It adds production hit-walker and texture regressions
and records Bean asset diagnostics in exported logs. This is a corrective
source build; visual mapping and DAB rendering parity remain unfinished.
It can join v0.4.16 through v0.4.19 sessions.

The launcher's **Mods** page imports XBLA / Project Bean meshes and textures
from your own copy of GoldenEye XBLA (its `.7z`, a `.zip`, or the Xbox 360
package); nothing of the release is downloaded. Select Bean under **Visuals**
alongside Original, HD and HD + AI.
Bean uses its own replacement textures exclusively, falling back to original
game textures for gaps. GE-X keeps its first-person guns, hands, watch and reloads.

Toggle Bean during play in **watch → VR options → Mods and fun**, or hold
one grip + right-stick click for one second. Right-stick click alone changes
play mode.

With Bean, the off hand that holds a gun with both hands is Bean's own arm,
pinned to the gun, and Bean's Gun fit starts from fits made on it.

**Gun fit** keeps each gun's own place in the hand and its own two-handed
hold, so fitting one pistol no longer moves another. Holding the off hand's
trigger places the holding hand by hand (it takes your off hand's place and
turn) or moves the gun with your off hand; the sticks still fine-tune it.

A tall character's view no longer rises above low doorways (Caverns'
tunnel doors), in solo and multiplayer.

Multiplayer's temporary health and armour gauges now appear when hit with
radar enabled. No knockback, keep firing when hit and red flash settings do
not suppress these gauges; the original health/armour animation remains.

Setup, supported fallbacks and the remaining headset checks are in
[Project Bean visuals](../project-bean.md). The original USA GoldenEye ROM
is still required. The APK contains no game data.

The reviewed implementation fixes Android compilation, Dam's vertex layout,
UV seams and scaling, texture indices and cache lifetime, colour and alpha,
bone weights, same-level toggles and room-matrix lifetime. Original water
rendering remains active with a Bean sky dome.

The mapping uses DAB's native asset aliases and fitted prop transforms:
457 native model rows, four-weight character skinning, attached heads,
six outfit sleeves for the watch and detonator, working clock/prop matrices,
and the ending helicopter's retained pilot. All 26 stage entries use original
room-triangle references, including Statue. Retail sky names are corrected.
DAB's broken civilians and unsupported geometry/material replacements retain
native fallbacks. Animated textures use their first frame and reflection
shaders remain simplified.

Validation: authored native regression fixtures, all 499 local CAFF files
(497 meshes and two expected N64 fallbacks), a 457-model/26-stage
ASan/UBSan mapping audit, and existing surface and GE-X checks. Signed ARM64 release build uses JDK 20.
The reported on-headset visual failures remain unresolved acceptance checks.
No APK installed by this task.
The 32 release JVM tests pass, including bounded archive extraction. Native
mode checks cover exclusive textures, live cache invalidation, watch/shortcut,
GE-X priority and all eight hit comfort combinations. Full Android lint still reports 35 errors in
unchanged Java code, mainly SDL Bluetooth permission checks; the normal
release assembly's fatal lint gate passes.
