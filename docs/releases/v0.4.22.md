# GoldenEye VR v0.4.22

Fixes co-op mission starts blocked by unused player bodies, including the
first player's Facility air vent. The mission intro also keeps your checked
start position intact when gameplay begins.

## Co-op starts (#164)

- Co-op reserves four player bodies even when the host plays alone. Unused
  bodies could block movement with invalid collision bounds. Empty, loading
  and departed player slots now stay out of collision checks, and every
  body's bounds are initialized at spawn.
- Real teammates keep the existing soft collision: they can pass one
  another instead of trapping each other in a vent or narrow corridor.
  Four-player parties keep the same rule.
- Intro animation no longer replaces the checked gameplay position or floor
  tile. Normal and skipped intros, repeated mission loads and a late join
  during the intro use the corrected handoff.

## Validation

- Quest 3 logs reproduced the Facility vent failure with the host alone and
  identified an unused player body as the blocker. The user retested the
  replacement and approved this release.
- Native collision and intro regressions pass, including vacant slots with
  invalid bounds, occupied teammates, full four-player parties, repeated
  loads, late-join corrections and offline controls. The regression fails
  on the previous build at the vacant body's movement-volume check.
- All 77 multiplayer regressions, 30 Android release unit tests and the
  twenty-mission floor audit pass.
- Broader two/four-headset starts, abort/reloads and host swaps still need
  play, especially Jungle, Train, Control, Caverns and Cradle. Check Jungle
  Natalya separately. Keep #164 open until those results are confirmed.

## Update and multiplayer compatibility

Download `GoldenEye-VR-v0.4.22.apk` or use **Update** in the headset launcher.
Updating over an earlier release keeps your settings. This APK contains no
GoldenEye, XBLA or Perfect Dark game data; use your existing game files.

Android version: `0.4.22`; versionCode: `78`; network protocol: `21`.
v0.4.16 through v0.4.22 share the same multiplayer protocol. Update every
co-op headset to get these fixes on each player's device.
