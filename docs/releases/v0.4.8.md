# v0.4.8

Android version name: `0.4.8`; version code: `61`; network protocol: `18`.
Combines PR #122 (co-op spawn collision fix) and PR #123 (immediate launcher
settings persistence and INI permission fix). Protocol 18 is unchanged.
No game data is shipped.

## Immediate launcher settings persistence and INI recovery — PR #123

- **Immediate save**: Launcher options across all tabs and subpages (Play mode,
  Turning, Turn speed, Movement comfort, Screen settings, Controls, Cheats,
  Gestures, Rules and Mods) persist immediately when toggled or adjusted,
  without requiring the player to click START or have a valid ROM loaded.
  Fixes [issue #113](https://github.com/MrSco/goldeneye-vr/issues/113).
- **Permission recovery**: Recovers file write permissions if `goldeneye-vr.ini`
  is stuck read-only (e.g. from backup restoration or file transfers), restoring
  write access on POSIX/Android and Windows.
- **Atomic file writes**: Writes to a temporary file before atomic replacement
  to protect against file truncation or corruption if the app is exited abruptly.
- **Exit hooks**: Flushes VR settings during application lifecycle cleanup
  and Android activity destruction.

## Co-op spawn unclogging in narrow mission starts — PR #122

- Co-op players can pass through each other during spawn in narrow mission starts
  (such as Facility's vent), preventing teammates from getting stuck or blocking
  each other.
- Competitive player collision and world/guard collision retain their original
  behavior. Fixes [issue #121](https://github.com/MrSco/goldeneye-vr/issues/121).

## Validation

- Native test suite passes across all 12 test suites, including read-only INI
  recovery in `test_vr_display.py`, launcher UI auto-save in `test_launcher_ui.py`,
  co-op spawn collision in `test_coop_collision.py`, and 64 multiplayer test cases.
- Android ARM64 release APK builds and signs cleanly with release key v2 scheme.
