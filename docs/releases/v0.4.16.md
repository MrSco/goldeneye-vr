# GoldenEye VR v0.4.16

Movement speed you can change during play. In multiplayer the host sets it
for the whole session, and it applies at once. Also: campaign co-op fixes for
Surface II, Bunker II, Jungle and co-op starts, and a launcher that fits a
full eight-player lobby without scrolling.

> **Bring your own game.** This APK contains no GoldenEye or Perfect Dark game
> data. You need a legally obtained ROM of the USA GoldenEye 007 cartridge you
> own. Installing over an earlier release keeps your ROM and settings.

> **Multiplayer compatibility.** The network protocol moves from **20** to
> **21**, because a match now carries the host's movement speed. **v0.4.15 and
> older can't join v0.4.16 games.** Everyone in a session needs this build.

## Movement speed — PR #165

- **Choose your speed.** 50% to 200% in 25% steps; 100% is the default. Solo
  and host settings are saved separately. Solo: launcher Comfort, or the
  watch's Game Options > VR Settings > Comfort during a mission. Host: launcher
  Multiplayer > Host > Match, or pause > Rules during a session.
- **It applies at once.** Solo changes take effect on the next step. A host's
  change updates the whole session, bots included, without a restart, a new
  round, or a ready reset. Clients see the host's percentage but can't change it.
- **Room-scale walking is unchanged.** Walking around your room stays 1:1.

## Launcher and fits

- **Two columns.** Match, Comfort and host lobby setup share two columns, so
  a full eight-player lobby fits. Roster rows are tighter; every name stays
  visible and Kick still asks first.
- **Custom weapons** use an Edit popup.
- **Chest and Belt defaults** use your saved Quest fits, scaled to height.
  Personal overrides are kept. See [body slots](../body-slots.md).
- **Watch controller.** The Controls model clears inherited world depth before
  drawing, so its shell is no longer hidden by the scene behind it.

## Campaign co-op fixes — #161 to #164

- **#161 Surface II.** Equipping a mine no longer makes a remote player's
  hand place a world mine the mission then rejects. Throws still work as before.
- **#162 Bunker II.** Collected documents are shared between host and clients.
  The comparison still needs both documents.
- **#163 Jungle.** Natalya no longer picks player bodies as guard targets.
- **#164 Co-op starts.** Parties start on the intended first pad, spaced
  apart with floor and scenery checks. Late joins use the same spacing.

Issues #161 to #164 stay open until headset play confirms them.

## Known issues and untested areas

- **Two headsets.** Host speed changes during a live match, client view, late
  join and host migration still need play on two headsets.
- **Campaign starts.** Co-op starts and the Surface II, Bunker II and Jungle
  checkpoints need headset play with two and four players.
- **Watch controller.** The Controls shell needs a headset look.
- **Solo Jungle.** A user playtest on this build saw Natalya following, shooting,
  walking and crouching normally. The mission wasn't completed.

## Validation

- **Automated.** All 37 Python test files pass, including 73 native multiplayer
  checks: live speed authority, readiness and countdown preservation,
  snapshots and host migration.
- **Android.** 24 unit tests pass.
- **Campaign regressions.** The #161, #162 and #163 regressions fail against
  the pre-fix commit `d048e74` and pass on this build.
- **Build.** The release APK is signed with the existing release key, and its
  v2 signature verifies.

## Installation

Use **Update** in the headset launcher when v0.4.16 appears, or install
`GoldenEye-VR-v0.4.16.apk` over your current version with SideQuest or ADB. It
uses the existing release signing key. See the
[install guide](https://github.com/MrSco/goldeneye-vr#-install-it-in-5-steps).

Android version: `0.4.16`; versionCode: `71`; network protocol: `21` (v0.4.15
and older can't join).
