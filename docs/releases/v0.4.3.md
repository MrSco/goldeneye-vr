# v0.4.3

- Left-handed ammo groups now match the physical hands in stereo VR and on the
  virtual screen, including each weapon's icon, magazine, reserve and switch state.
- Dual-wield reload buttons operate independently. Physical B reloads the right
  hand, physical Y the left; either button reloads a single equipped weapon.
  Doors, switches, tank controls, microphone chords and menus retain their priority.
- The existing wrist watch shows live classic health and armor arcs, plus
  multiplayer radar, while keeping its mission-time clock hands. Holster the
  offhand to see it; weapon-holding arms and two-hand grips retain their visibility.
- Controls now offers **Watch face status: Off / On / Only**, defaulting to **On**
  for new installs and configurations missing the setting. Only hides standard
  gameplay status in stereo; pause-menu status and damage tint remain. Screen mode
  keeps standard displays. **Watch gesture to pause** is a separate, saved toggle,
  enabled by default; the Menu button continues to pause when it is disabled.
- [Multiplayer issue #106](https://github.com/MrSco/goldeneye-vr/issues/106):
  in-game Ready choices reach the host and remain saved until changed or pending
  round options change. Start match requests readiness even when someone is
  waiting; the host can also start a new round from the active match. Alone, **Restart
  warmup** applies pending map/rules choices and reloads a joinable solo warmup.
- The pause roster shows every connected player, including loading players and
  spectators, with their status. The host can **Kick** a player from the launcher
  lobby or pause menu after confirming their name. Kicked clients return to the
  launcher without electing a new host.
  Guests advertise support for removal; older builds keep protocol-17 gameplay
  compatibility and show a disabled Kick control with an update explanation.
  Install this build on all headsets for kicks and gameplay reminders.
- Ready requests and **Request votes** show repeated gameplay messages, including
  for spectators with their menus closed. Match results also request readiness
  and, in Vote mode, next-map/weapon votes.
- First and subsequent multiplayer rounds load into **two minutes of warmup**.
  The chosen next map is available for practice before its countdown. Once the
  timer ends and everyone is ready and loaded, the match starts with a
  **ten-second countdown**; the host can start that countdown earlier. Cancel
  start holds warmup until the host requests another start. A lone host keeps
  warming up. Practice scores, deaths and pickups reset at the match boundary.
- Remote body animations advance from the local online viewport rather than
  split-screen shuffle order. Copies restore received heading, pitch and view
  direction after their movement tick. The early respawn shortcut waits for the
  falling animation before skipping the blood/fade wait.
- Launcher Controls uses two equal columns: hands, aiming and weapon controls on
  the left; haptics and watch settings on the right. The watch choices and their
  explanation fit without scrolling at the headset's launcher scale.

Android version name: `0.4.3`; version code: `56`; network protocol remains `17`.

## Validation

Native regression harnesses compile the production ammo renderer, physical-button
mapping, per-hand reload sampling/activation routing, watch dial measurement and
overlay renderer. They cover unequal magazines, mixed weapons, shared reserves,
switch suppression, overlapping button holds, queued releases, interaction/tank
priority, microphone chords, blocked input, context changes, high local player
slots, live local gauges, radar orientation, mirrored watch transforms, geometry
allocation boundaries, packed wrist-transform precision and gesture
cancellation/rearming.

Settings tests link the actual reader, writer and platform defaults. All three
status choices and both gesture choices round-trip on desktop and Quest; absent
and malformed status values default to On. Watch-grip, display lifecycle,
launcher and pause/radar regressions pass, along with all 59 multiplayer checks
and 20 Android unit tests. The signed Android release APK builds successfully;
its package metadata and signature are verified.

Multiplayer additions cover authenticated in-game Ready packets, malformed and
unauthorized requests, unready/countdown cancellation, pending settings, complete
team rosters, solo warmup restarts and loading guards. They also cover
connected spectators/loading players, spectator load acknowledgments, first and
next warmup timers, early/canceled starts, late joins during a countdown, voted
map warmups, authenticated advisory packets, ready/vote prompts, host kick
authority and removal without host migration. Pause checks cover eight visible
rows, status/button widths and kick confirmation at the headset font scale.
Presentation checks cover all local slots and shuffle positions, body/view heading agreement and the
death-skip gate. Launcher checks draw the actual Controls content and verify both
columns fit with the watch description wrapping inside the right column.

## Headset validation

The maintainer tested the build, reported that it feels good, and approved
publishing v0.4.3 with further multiplayer testing in production.

Continue checking wrist readability and clock visibility in both
handedness modes; live damage/armor and multiplayer radar; Off/On/Only and gesture
pause; independent reloads while firing the opposite gun; doors and microphone
chords; switching, holstering, watch gadgets, two-hand holds and stage changes.
Use a two-headset match to confirm persistent Ready, host starts/restarts,
forward-facing movement and visible death animations. Disconnect the guest and
change maps from the host's solo warmup without leaving for the launcher.
Also test a late spectator joining while the host requests readiness, ready/vote
prompts with menus closed, kicking that spectator, and consecutive two-minute
warmups with an early host start and a canceled countdown.
Automated renderer checks and a successful APK build do not establish headset
readability or stereo comfort.
