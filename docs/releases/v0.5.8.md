# GoldenEye VR v0.5.8

Quitting closes the game at once, and reopening it straight away no longer
brings up an "isn't responding" dialog.

## Fixes

- **Quit from the Meta menu:** the game used to hang for about ten seconds
  after Quit, until the system ended it. Reopening it from the Library in
  that time gave a window that never appeared, then an "isn't responding"
  dialog (crash report 37093815). The game now saves its settings, closes
  audio and leaves the lobby as before, then ends at once (PR #205).
  [Details](https://github.com/MrSco/goldeneye-vr/blob/main/docs/crash-37093815-quit-anr.md).

## Testing and known issues

- Checked on Quest 3: Quit from the Meta menu, Quit then an immediate reopen
  from the Library, hold Menu to return to the launcher. The headset's exit
  history shows each quit ending at once, with no destroy timeout.
- Everything listed under v0.5.7's known issues still applies.

## Update and multiplayer compatibility

Download `GoldenEye-VR-v0.5.8.apk` or use **Update** in the headset launcher.
Updating over an earlier release keeps your settings. This APK contains no
GoldenEye, XBLA or Perfect Dark game data; use your existing game files.

Android version: `0.5.8`; versionCode: `88`; network protocol: `23`.
No network changes: v0.5.7 and v0.5.8 play together; v0.5.6 and older can't
join.
