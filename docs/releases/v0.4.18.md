# GoldenEye VR v0.4.18

The watch's Control page now shows the Quest Touch controllers in your hands
and what each control does, and the off hand's trigger no longer aims.

> **Bring your own game.** This APK contains no GoldenEye or Perfect Dark game
> data. You need a legally obtained ROM of the USA GoldenEye 007 cartridge you
> own. Installing over an earlier release keeps your ROM and settings.

> **Multiplayer compatibility.** The network protocol stays at **21**. v0.4.16,
> v0.4.17 and v0.4.18 play together; nothing in a match's messages changed.

## Touch controllers on the watch — PR #166

- **Your controllers, not the N64 pad.** The watch's Control page used to show
  the N64 controller. It now shows the Touch controllers for your headset:
  Quest 1, Quest 2, Touch Plus (Quest 3 and 3S) or Touch Pro. To pick a set
  yourself, for example Touch Pro controllers paired to a Quest 3, use
  **VR settings → Controls → Controllers** on the watch.
- **What each control does.** Under each controller is a list of its controls
  and what they do right now. It follows the play mode, left-handed mode,
  Swap sticks, what your off hand holds, Grip use and the other grip gestures,
  and Motion throwing. A change in the watch's VR settings shows as soon as
  you go back to the page.
- **Live controls.** Pull a trigger, squeeze a grip, push the stick or press a
  button: that part moves on the model and lights green, and its line turns
  white. As with the N64 controller, select the page's Controller row and use
  the stick to spin and tilt the pair.
- The models are Meta's controller art, used to show the controllers.

## Off-hand trigger

- **No more crosshair from the off hand's trigger.** In stereo, an empty off
  hand's trigger aimed, which showed your gun hand's crosshair. Your gun
  hand's grip already does that. The off hand's trigger now fires or throws
  what that hand holds and does nothing when it's empty. With GoldenEye X
  remote mines out, it still sets them off.

## Known issues and untested areas

- **Two headsets.** Bots, host speed changes, client view, late join and host
  migration still need play on two headsets.
- **Campaign co-op (#161 to #164).** These issues are closed with this
  release; the fixes have been in since v0.4.16. Solo Natalya on Jungle was
  checked in the headset. Two- and four-player co-op checks are still owed.
  Reopen an issue if it comes back.
- **Touch controller sets.** Touch Plus on a Quest 3 was tested in the
  headset. The Quest 1, Quest 2 and Touch Pro models were checked in PC
  previews of the page.

## Validation

- **Automated.** All 38 Python test files pass. The watch controller test
  now runs the Controls page with the Touch pair: one depth clear before it,
  opaque and fading.
- **Headset.** The user tested a build of these changes on a Quest 3 before
  release.
- **Build.** The release APK is signed with the existing release key, and its
  v2 signature verifies.

## Installation

Use **Update** in the headset launcher when v0.4.18 appears, or install
`GoldenEye-VR-v0.4.18.apk` over your current version with SideQuest or ADB. It
uses the existing release signing key. See the
[install guide](https://github.com/MrSco/goldeneye-vr#-install-it-in-5-steps).

Android version: `0.4.18`; versionCode: `73`; network protocol: `21` (v0.4.16
and v0.4.17 can join).
