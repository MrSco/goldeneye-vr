# GoldenEye VR v0.4.13

A crash fix release: two Quest crashes from the same evening, one on returning
to the title and one when a full sound queue hung the game.

> **Bring your own game.** This APK contains no GoldenEye or Perfect Dark game
> data. You need a legally obtained ROM of the USA GoldenEye 007 cartridge you
> own. Installing over an earlier release keeps your ROM and settings.

> **Multiplayer compatibility.** The network protocol is unchanged at **19**, so
> v0.4.11, v0.4.12 and v0.4.13 players can play together.

## Crash fixes — PR #151

- **Returning to the title.** Going back to the title from a stage (seen after
  Statue on Quest 2) could crash in sound-path setup. The title loads no
  background, so the previous stage's portal table had already been freed with
  the stage memory. The table is now cleared when the stage memory resets, and
  the next real stage sets it again.
  See [crash 65a366e6](../crash-65a366e6-title-portals.md).
- **Full sound queue.** A burst of sounds (seen with five bots starting an
  Archive round on Quest 3) could fill the 64-slot sound queue and drop the
  event that keeps the sound player ticking. The player then never returned to
  the audio driver, and the watchdog ended the game. An empty queue now waits
  one frame, the dropped tick is posted again as soon as a slot frees, and the
  sound and music handlers stop after 256 back-to-back zero-delay events and
  carry on next frame. See [crash bfb06b31](../crash-bfb06b31-sfx-queue.md).

## Testing

- All 26 native regression suites passed, including new tests for a cleared
  portal table and for an empty, all-zero-delay and full sound queue.
- The release APK builds and is signed with the existing release key.
- Neither crash has been reproduced on a headset since the fix; the evidence is
  the crash reports and the fixtures that recreate them.

## Installation

Use **Update** in the headset launcher when v0.4.13 appears, or install
`GoldenEye-VR-v0.4.13.apk` over your current version with SideQuest or ADB. It
uses the existing release signing key. See the
[install guide](https://github.com/MrSco/goldeneye-vr#-install-it-in-5-steps).

Android version: `0.4.13`; versionCode: `68`; network protocol: `19` (unchanged).
