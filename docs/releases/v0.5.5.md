# GoldenEye VR v0.5.5

A launcher fix for v0.5.4: the AI ally's settings get their own page, and
**Game rules** fits on screen again.

## AI ally page

- **Play → Game rules…** shows one **AI ally (Natalya)…** button; it reads
  **(on)** while she's enabled.
- The button opens her page: on/off, weapon, aggression, damage, invincible
  and health, with **Done** back to Game rules.
- In v0.5.4 those six controls sat on Game rules itself and made the page
  scroll. Every launcher page fits without scrolling again.
- Your saved ally choices carry over unchanged.

## Validation

- Checked on Quest 3: both pages, opening and closing the ally page.
- Host tests: the full port/tests suite. The launcher check now draws both
  pages at the headset's size and fails if either overflows or any part of
  it scrolls.

## Update and multiplayer compatibility

Download `GoldenEye-VR-v0.5.5.apk` or use **Update** in the headset launcher.
Updating over an earlier release keeps your settings. This APK contains no
GoldenEye, XBLA or Perfect Dark game data; use your existing game files.

Android version: `0.5.5`; versionCode: `85`; network protocol: `22`.
v0.5.4 and v0.5.5 play together; v0.5.3 and older can't join.
